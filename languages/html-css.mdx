## Language server

| Language | Server | Install |
|---|---|---|
| HTML | [vscode-html-language-server](https://github.com/microsoft/vscode-html-languageservice) | `npm install -g vscode-langservers-extracted` |
| CSS / SCSS / Less | [vscode-css-language-server](https://github.com/microsoft/vscode-css-languageservice) | `npm install -g vscode-langservers-extracted` |

`class="…"`/`id="…"` autocomplete and jump-to-definition in HTML/PHP templates resolve against linked stylesheets and inline `<style>` blocks — see [Language Intelligence](/lsp) for that feature generally.

## Debugger

Not applicable — HTML/CSS have no execution model to step through. Debug the JavaScript on the page instead, see [TypeScript / JavaScript](/languages/typescript).

## Tested on

macOS (Apple Silicon). Windows and Linux paths aren't documented yet.
